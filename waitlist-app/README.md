# 바이브 코딩 체험 부스 대기자 관리 시스템

노원수학문화축전 · 인덕과학기술고등학교 바이브 코딩 체험 부스용 대기자 관리 웹앱입니다.
Google Sheets를 DB로, Apps Script 하나로 참가자 접수/스태프 대시보드/전광판 페이지를 모두 서빙합니다.

## 파일 구성
- `Code.gs` — 서버 로직 (등록, 상태 조회, 호출, 완료 처리 등)
- `Index.html` — 참가자 접수 및 내 번호 확인 페이지
- `Staff.html` — 스태프용 대기열 관리 대시보드
- `Board.html` — 현장에 띄울 전광판 화면
- `Style.html` — 공통 스타일
- `appsscript.json` — 프로젝트 매니페스트 (웹앱 배포 설정)

## 배포 방법 (개인 Gmail 계정 기준)

1. **Google Sheets에서 새 스프레드시트 생성**
   아무 이름이나 상관없습니다 (예: "바이브코딩 대기자 관리").

2. **확장 프로그램 > Apps Script** 클릭해 스크립트 편집기를 엽니다.

3. 편집기에 이 폴더의 5개 파일을 그대로 만들어 넣습니다.
   - `Code.gs` (기본 생성된 `Code.gs`에 덮어쓰기)
   - `Index.html`, `Staff.html`, `Board.html`, `Style.html` (파일 > 새 파일 > HTML 로 각각 생성)
   - 프로젝트 설정에서 `appsscript.json` 내용도 동일하게 맞춰줍니다 (편집기 좌측 톱니바퀴 > "appsscript.json 매니페스트 파일을 편집기에 표시" 체크 후 편집).

4. **`initializeSheet` 함수를 한 번 실행**합니다.
   - 편집기 상단 함수 선택 드롭다운에서 `initializeSheet` 선택 후 실행 버튼
   - 처음 실행 시 권한 승인 창이 뜨면 본인 계정으로 승인
   - 실행 후 **실행 로그(보기 > 로그)** 에서 `스태프 접근 코드: XXXXXX` 를 확인하고 기록해두세요. 이 코드가 스태프 페이지 로그인 코드입니다.

5. **배포 > 새 배포** 클릭
   - 유형: **웹 앱**
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자** (참가자가 로그인 없이 접속해야 하므로)
   - 배포 후 나오는 **웹 앱 URL**을 복사해둡니다.

6. URL 뒤에 파라미터를 붙여 용도별 페이지로 접속합니다.
   - `<웹앱URL>?page=join` — 참가자 접수 페이지 (QR코드로 배포)
   - `<웹앱URL>?page=staff` — 스태프 대시보드 (4번에서 확인한 접근 코드로 로그인)
   - `<웹앱URL>?page=board` — 전광판 (현장 모니터/태블릿에 띄우기)

7. `<웹앱URL>?page=join` 을 QR코드로 만들어 부스에 비치합니다.

## 코드를 수정했을 때
Apps Script는 코드를 저장해도 배포된 URL에는 바로 반영되지 않습니다.
**배포 > 배포 관리 > 수정(연필 아이콘) > 새 버전으로 배포**를 눌러야 웹앱에 반영됩니다.

## 운영 설정값 조정
스크립트 편집기 좌측 톱니바퀴 > **프로젝트 설정 > 스크립트 속성**에서 아래 값을 바꿀 수 있습니다.
- `MAX_WAITING` — 대기 접수를 잠시 중단할 최대 대기 인원 (기본 30)
- `AVG_MINUTES` — 1인당 평균 체험 시간(분), 예상 대기시간 계산에 사용 (기본 8)
- `STAFF_CODE` — 스태프 페이지 접근 코드 (직접 원하는 값으로 바꿔도 됩니다)

## 행사 전 체크리스트
- [ ] `initializeSheet` 실행 및 스태프 코드 확인
- [ ] 웹앱 배포 후 `?page=join` / `?page=staff` / `?page=board` 각각 접속 테스트
- [ ] 스태프 대시보드에서 호출 → 진행 → 완료 흐름 실제로 눌러보며 확인
- [ ] 여러 기기(휴대폰 여러 대)로 동시 접수 테스트 — Google 개인 계정은 동시 실행 할당량이 제한적이므로, 실제 참가자 수보다 넉넉하게 동시 접속 테스트 권장
- [ ] 전광판용 기기(태블릿/노트북)에 `?page=board` 를 전체화면으로 띄워두기
- [ ] 장애 대비: 종이 대기표 예비로 준비
